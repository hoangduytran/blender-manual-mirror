**************************
Grease Pencil Fill ID Node
**************************

.. figure:: /images/node-types_GeometryNodeGreasePencilFillID.webp
   :align: right
   :alt: Grease Pencil Fill ID Node.

The *Grease Pencil Fill ID* node outputs the fill ID of each Grease Pencil stroke.
The fill ID can be used to identify and group strokes based on their fill.


Inputs
======

This node has no inputs.


Outputs
=======

Fill ID
   The fill ID of the stroke.
