************************
Grease Pencil Color Node
************************

.. figure:: /images/node-types_GeometryNodeGreasePencilColor.webp
   :align: right
   :alt: Grease Pencil Color Node.

The *Grease Pencil Color* node outputs the color attributes of Grease Pencil strokes.
Separate outputs are provided for the stroke points and the stroke fill.


Inputs
======

This node has no inputs.


Outputs
=======

Point
   The color of each point in the stroke.

Fill
   The fill color of the stroke.
