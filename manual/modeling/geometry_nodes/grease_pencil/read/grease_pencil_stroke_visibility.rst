************************************
Grease Pencil Stroke Visibility Node
************************************

.. figure:: /images/node-types_GeometryNodeGreasePencilStrokeVisibility.webp
   :align: right
   :alt: Grease Pencil Stroke Visibility Node.

The *Grease Pencil Stroke Visibility* node outputs whether Grease Pencil strokes are hidden.
It can be used to access the visibility state of strokes and use it as a selection or condition
in a geometry node tree.


Inputs
======

This node has no inputs.


Outputs
=======

Is Hidden
   Boolean value indicating whether the stroke is hidden.
