**************************
Grease Pencil Opacity Node
**************************

.. figure:: /images/node-types_GeometryNodeGreasePencilOpacity.webp
   :align: right
   :alt: Grease Pencil Opacity Node.

The *Grease Pencil Opacity* node outputs the opacity values of Grease Pencil strokes.
Separate outputs are provided for the stroke points and the stroke fill.


Inputs
======

This node has no inputs.


Outputs
=======

Point
   The opacity of each point in the stroke.

Fill
   The opacity of the stroke fill.
