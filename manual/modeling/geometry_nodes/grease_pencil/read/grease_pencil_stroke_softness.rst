**********************************
Grease Pencil Stroke Softness Node
**********************************

.. figure:: /images/node-types_GeometryNodeGreasePencilStrokeSoftness.webp
   :align: right
   :alt: Grease Pencil Stroke Softness Node.

The *Grease Pencil Stroke Softness* node outputs the softness value of each Grease Pencil stroke.
This value controls the amount of softness applied to the edges of the stroke.


Inputs
======

This node has no inputs.


Outputs
=======

Softness
   The softness value of the stroke.
