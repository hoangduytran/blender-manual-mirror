*****************
Separate XYZ Node
*****************

.. figure:: /images/node-types_ShaderNodeSeparateXYZ.webp
   :align: right
   :alt: Separate XYZ Node.

The *Separate XYZ Node* splits a vector into its individual components.

.. tip::

   To retrieve a vector component dynamically using an index,
   use the :doc:`Get Vector Component </modeling/geometry_nodes/utilities/vector/get_vector_component>` node


Input
=====

Vector
   Standard vector input.


Outputs
=======

- X
- Y
- Z
