*************************
Get Vector Component Node
*************************

.. figure:: /images/node-types_FunctionNodeGetVectorComponent.webp
   :align: right
   :alt: Get Vector Component node.

The *Get Vector Component* node retrieves an individual component of a vector using its index.


Inputs
======

Vector
   The vector from which to retrieve a component.

Index
   Index of the component to retrieve:

   - **0:** X component.
   - **1:** Y component.
   - **2:** Z component.


Outputs
=======

Value
   The value of the selected vector component.
